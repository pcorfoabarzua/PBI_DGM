# PBI_DGM

Repositorio del proyecto **Power BI DGM**, desarrollado en formato **PBIP** para
permitir versionamiento, trazabilidad de cambios y trabajo colaborativo mediante GitHub.

## 📊 Alcance del proyecto
El proyecto incluye análisis y visualizaciones relacionadas con:
- Pelágicos (Sur y Norte)
- Crustáceos Demersales
- Aguas profundas
- Bentónicos
- Crustáceos Bentónicos
- Jibia
- SRAM

## 🧱 Estructura del proyecto
- Modelo de datos en formato PBIP
- Transformaciones de datos en Power Query
- Medidas DAX
- Dashboards y tooltips analíticos

## 🌿 Flujo de trabajo Git
- Rama principal: `main`
- Correcciones de errores y datos: `fix/*`
- Nuevas funcionalidades: `feature/*`
- Cambios integrados mediante Pull Requests
